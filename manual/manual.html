01Overview

このシステムでできること

問い合わせ・案件・スタッフ・タスク・実績を1か所にまとめ、「いま何が終わっていて、次に何をするか」が見えるようにするための道具です。AIですべてを自動で進めるものではありません。

  • 情報を1か所で管理　案件・お客さま・スタッフ・実績が、つながって見られます。
  • 進み具合が見える　案件は8つのステータスで進みます。今どこにいるかが、いつでも分かります。
  • 抜け漏れを防ぐ　期限切れのタスクや、足りないスタッフの数を、赤い印で知らせます。
  • 決まった形の作業をAIが手伝う　問い合わせの整理、返信文・見積のご案内文・申込書・依頼文・引き継ぎメモの下書きを作ります。
  • 申込・シフト・請求までつなぐ　Googleフォームの申込内容の確認、常設託児室のシフト表、交通費と請求に必要な情報のまとめまで、同じ画面で扱います。

03Procedures

業務の手順

問い合わせを受けてから、実績を記録するまでを、順に説明します。

3.1　問い合わせが届いたとき（AIで整理して、案件にする）

メールやフォームで届いた問い合わせの文章を貼り付けると、AIが「開催日・時間・会場・子どもの人数・年齢構成・確認事項」に分けます。人が確かめて直したあとで、案件として登録します。

  1. 「AIアシスタント」を開くダッシュボードの「問い合わせを整理する」からも開けます。
  2. 1文章を貼り付ける届いた文章を、そのまま入れます（3,000文字まで）。試すときは、2の例文のボタンで、サンプルの文章が入ります。
  3. 3「整理する」を押す数秒で結果が出ます。
  1. 1取り出せた項目を見る取り出せた項目には✓が、文章の中に見つからなかった項目には赤い「見つかりません」が出ます。見つからなかったことは、「確認事項」に入ります（お客さまに聞くことのメモになります）。
  2. 2入力欄を、原文と見比べて直す案件名・開催日・時間・会場・人数などが、入力欄に入っています。まちがいや抜けを直し、足りない所は、お客さまに確かめてから入れます。案件名と開催日は必須です。
  3. 確かめた印をつけて、「案件に登録」を押す「整理した内容を確かめ、足りない所を直しました」に印をつけるまで、登録のボタンは押せません。

登録すると、次のことが自動で行われます。

  • ステータスが「問い合わせ」の案件が作られ、案件の詳細が開きます。
  • 問い合わせの原文が、案件の詳細に残ります。
  • 翌日が期限の、「ヒアリング（確認事項の聞き取り）」のタスクが作られます。
AIの読みまちがいに注意

AIは、日付・時間・人数などの決まった書き方から取り出しています。ほかの案件との日時のかさなりや、書かれていない事情は、見つけられません。たとえば、日付が過ぎている・曜日が日付と合わない場合は、確認事項に出しますが、直すのは人です。必要スタッフ数は、人数と年齢を見て、人が決めます。

AIを使わずに登録するとき

「案件」を開き、右上の「案件を登録」を押します。案件名と開催日が必須です。子ども人数と必要スタッフ数は、分からなければ空のまま（画面では「未入力」）にします。0人のときは、0と入れます。

3.2　案件を進める（進み具合とステータス）

案件を開くと、いちばん上に「進み具合」が出ます。案件は、問い合わせ → ヒアリング → 見積 → 申込確認 → スタッフ手配 → 最終確認 → 実施済み → 完了、の8つのステータスで進みます。

  1. 1進み具合済んだ段階は✓、今の段階は太い枠で出ます。
  2. 2今やること今のステータスで、人がやることの目安です。
  3. 3「次のステータスに進める」・「1つ戻す」1つずつ進み、1つずつ戻ります。戻しても、タスクや担当スタッフは残ります。
  4. 4案件の情報開催日・時間・会場・子ども人数・年齢構成・必要スタッフ・確認事項・託児メモです。直すときは、右上の「案件を編集」を押します。
  5. 5顧客情報お客さまの名前・担当者・電話・メールです。

進める前に出る「知らせ」

次のステータスに進めるとき、まだ終わっていないことがあると、知らせが出ます。知らせは止めるものではありません。内容を見て、進めてよいかを担当者が決めます（「このまま進める」または「キャンセル」）。

進めるとき出る知らせ
「スタッフ手配」に進める必要スタッフ数がまだ入っていません
「スタッフ手配」から進める確定したスタッフがあと○名足りません／返事待ち（依頼中）のスタッフが○名います
「実施済み」に進める開催日より前です
「完了」に進める実績がまだ登録されていません／終わっていないタスクが○件あります

定型タスクが作られます

ステータスを進めると、そのステータス用の定型タスクが、期限と担当者（案件の担当者）つきで自動で作られます。同じ名前のタスクは、重ねて作られません。使わないタスクは、3.7で外せます。

申込確認Googleフォームを案内する（当日）／申込フォームの回答を確認する・必要スタッフ数を決める（2日後）

案件を探す

「案件」の一覧では、検索（案件名・会場・顧客名）、ステータス、開催日（今日以降・今週・今月・来月・過去）で絞り込めます。一覧には、開催日・時間・会場・子どもの人数・必要スタッフ数・確定数・ステータス・担当者・次のタスクが並びます。完了していない案件が、開催日の近い順に上に出ます。

3.3　申込フォーム（Googleフォーム）の回答を確認する

お客さまがGoogleフォームで申し込むと、回答は自動でシステムに届きます（担当者が表をコピーする必要はありません）。届いた回答は「未確認」として並び、システムが案件と自動で突き合わせて、ちがう所を見つけます。案件に反映するかどうかは、人が確かめて決めます。システムが案件を勝手に書き換えることはありません。自動で届くのは、フォームに付けた小さなスクリプト（Google Apps Script。導入のときに管理者が設定します）が、回答をシステムへ送るからです。

  1. 「案件」の上の「未確認の回答」を押す届いた回答の数（「未確認の回答 3件」）が出ています。案件の詳細の「申込フォーム」の欄でも、その案件の回答を見られます。
  2. 確かめる回答を選ぶ回答が1件ずつ並びます。押すと、案件との突き合わせの結果が出ます。
  3. 1取り込む案件を確かめる開催日・顧客名・イベント名が近い案件が、自動で選ばれます。ちがうときは選び直します。一致する案件がなければ、「新しい案件として登録する」を選びます（ステータス「申込確認」で作られます）。
  4. 2見つかったかを見る「案件が見つかりました」か、「一致する案件がありません」が出ます。
  5. 3項目ごとの結果を見る「一致」「相違」（案件の登録とちがう）「案件にない」（案件が空で、回答にある）「未入力」（回答が空）です。相違の行は赤くなります。
  6. 46案件に反映する項目を選ぶ「案件にない」は、はじめから反映する印がついています。「相違」は、どちらが正しいかを、お客さまに確かめて決めるので、はじめは反映しません。反映するときは、印をつけます。
  7. 5「内容を確かめました」に印をつけて、「確認済みにする」を押す印をつけるまで、押せません。

確認済みにすると、案件の詳細の「申込フォーム」の欄に回答が残り、その案件の「申込フォームの回答を確認する」タスクが完了になります。同じ回答は、重ねて届いても、重ねて保存されません。

返信文にフォームの案内が入ります

ステータスが「見積」「申込確認」のときの返信文と、見積のご案内文には、Googleフォームの案内（URL と、入力してもらう項目）が入ります。URL は、「案件」の「Googleフォームの設定」で入れます（https で始まる URL だけ）。入れていないときは、〔GoogleフォームのURL〕と出ます。

見本のデモでは

この手引きは、実際の業務で使う形（サーバー版）を前提に書いています。見本のデモには自動で届く仕組みがないため、スプレッドシートからコピーした表を貼り付けて取り込みます（「案件」の「申込フォームの回答を取り込む」）。届いたあとの突き合わせと確認の流れは、同じです。

3.4　スタッフを手配する（候補を探して、依頼中→確定）

案件の詳細の「担当スタッフ」で、必要な人数のスタッフをそろえます。「確定 2 / 必要 4 ▲不足2 依頼中 1」のように、確定した人数・必要な人数・足りない人数・返事待ちの人数が出ます。

  1. 1「スタッフ候補を探す」を押す案件に、開催日と、開始・終了の時刻が入っていることが必要です（入っていないと、探せない旨が出ます）。
  2. 3候補を見るシステムが、次の4つに当てはまる人だけを出します。経験年数の長い人が上です。
    • 稼働できる状態である（休止中ではない）
    • 開催日の曜日に対応できる
    • 対応できる時間が、案件の時間をすべて含んでいる
    • 同じ日の同じ時間に、ほかの案件の担当・常設託児室のシフトの枠に入っていない
  3. 4「依頼中で追加」を押すスタッフが「依頼中」で担当に加わります。システムはスタッフに連絡しません。依頼の連絡は、電話やチャットで担当者が行います（依頼文は、3.6のAIで下書きできます）。
  4. 2返事をもらったら「確定」にする担当スタッフの右にある選択で、「依頼中」を「確定」に変えます。
  5. 外すとき右の「×」を押します。確認が出ます。連絡をしていた場合は、取り消しの連絡を別に行ってください。
  6. 5条件に合わない人を見る「条件に合わない○名」を押すと、名前と理由（曜日が合わない・時間が合わない・休止中・同じ時間にほかの予定）が出ます。時間の相談などに使えます。

交通費を記録する

担当スタッフごとに、交通費を記録します。請求に必要な情報になるので、確定したスタッフの分は、確定の印まで入れます。

  1. 1金額と状態を見る「交通費 ¥1,200（未確認）」のように出ます。未確認は、まだ確かめていない金額です。
  2. 2「交通費を入れる」（「交通費を直す」）を押す金額（円）・経路のメモ・「金額を確認して、確定にする」を入れます。かからないときは 0、分からないときは空のまま（未入力）にします。確定にするには、金額（0でもよい）が必要です。
  3. 3確定したスタッフで、未入力のときは赤い印「確定」なのに交通費が未入力のスタッフには、赤い印が出ます。請求準備（3.9）でも、足りないこととして知らせます。
スタッフの登録

「スタッフ」の画面で、名前・ステータス（稼働可／休止中）・対応できる曜日と時間・資格・経験年数・対応経験・備考を登録・編集します。スタッフの名前を押すと、その人が担当する案件が見られます。候補は、ここに登録された曜日と時間で探します。予定が変わったら、更新してください。

3.5　シフト表（常設託児室の枠を手配する）

「スタッフ」の上のタブから「シフト表」を開きます。常設託児室3か所の枠（1つの枠＝1人分の勤務の時間）と、イベント託児の案件、スタッフの予定を、1週間の表で見ます。「未手配」の枠を探して、スタッフを手配するのが主な使いかたです。

  1. 1週を動かす「前の週」「今週」「次の週」で動かします。この週の枠の数（確定・依頼中・未手配）が、表の上に出ます。
  2. 2見かたを切り替える「場所別」（行＝常設託児室3か所と案件）、「スタッフ別」（行＝スタッフ。対応できない曜日は「対応外」、その週に入る時間数つき）、「タイムライン」（1日を横向きの時間軸で見る。下で説明）、「月」（日ごとの枠の状況。日を押すと、その週の表が開く）です。
  3. 3赤い枠（未手配）を探すだれも入っていない枠は、赤い枠と「未手配」の文字で出ます。
  4. 4依頼中・確定を見分ける点線の枠は「依頼中」（返事待ち）、青い塗りは「確定」です。
  5. 5案件の行を見る同じ日のイベント託児の案件も出ます（押すと案件の詳細が開きます）。スタッフの重なりを避けるための目安になります。

タイムラインで、1日の時間を見る

「タイムライン」は、1日を、8時〜20時ごろの横向きの時間軸で見る表示です。「だれが、何時から何時まで入るか」「何人が、何時に同時に入るか」が、横の長さで分かります。時間が広い予定があるときは、時間軸が自動で広がります。

  1. 1日を動かす「前の日」「今日」「次の日」で、日を動かします（今日を見ているときは、いまの時刻に赤い縦線が出ます）。
  2. 2「タイムライン」を選ぶほかの見かたに切り替えても、見ていた日・週が引き継がれます。
  3. 3棒で、入る時間を見る棒の左端が始まり、右端が終わりです。棒には、時間と、場所（案件のときは案件名）が出ます。棒を押すと、枠は手配の画面、案件は案件の詳細が開きます。
  4. 4薄い帯で、稼働できる時間を見るスタッフに登録された「対応できる時間」です。帯の外に棒があれば、登録とずれているので確かめてください。「休止中」「対応外」の人は、帯が出ません。
  5. 5名前の下の時間を見るその日の最初〜最後の時間と、合計の時間です。予定のある人が上に、始まりの早い順に並びます。

下の「場所別」では、場所ごとに、枠が何人分どの時間に入るかを見ます。同じ時間に重なる枠は、上下に分けて出します。だれも入っていない枠は赤い「未手配」で出ます。

枠にスタッフを手配する

  1. 枠を押す手配の画面が開きます（タイムラインの棒からも開けます）。
  2. 1スタッフを選ぶ選べるのは、その枠に入れる人だけです（稼働できる・曜日と時間が合う・同じ時間にほかの枠や案件がない）。経験年数の長い人が上に並び、「この週 ○時間」で、すでに入っている時間も分かります。
  3. 2状態を選ぶ連絡して返事待ちのときは「依頼中」、決まったら「確定」です。システムは、スタッフに連絡しません。連絡は、担当者が行います。
  4. 3入れない人を見る名前と理由（曜日・時間・休止中・ほかの予定）が出ます。時間の相談に使えます。
  5. 4枠を削除するとき確認が出ます。入っている人は外れ、元には戻せません。

枠を作る（定期シフトと、臨時の枠）

  • 定期シフトの設定　場所ごとに、曜日・時間・人数のパターン（例: 月〜金 10:00〜14:00・2名）を決めます。
  • この週の枠を作る　表示している週に、定期シフトから足りない枠を作ります。すでにある枠は、重ねて作りません。週が変わるたびに、押してください。
  • 枠を追加　定期シフトにない臨時の枠を、1回だけ作ります（枠の数は 1〜10）。
スタッフの予定が変わったら

枠の候補は、「スタッフ」に登録された曜日・時間で探します。予定が変わったら、先にスタッフの登録内容を直してください。案件のスタッフ候補（3.4）も、シフトの枠との重なりを見て探します。

3.6　文章の下書きを作る（返信文・見積のご案内文・申込書・依頼文・引き継ぎメモ）

案件の情報から、5種類の文章の下書きを作れます。案件の詳細の右側「AIアシスタント」か、「AIアシスタント」の画面（案件を選ぶ）から使います。

種類作られるもの
顧客への返信文案件のステータスに合わせた、丁寧な返信の文（問い合わせ・見積・申込・スタッフ手配・最終確認・実施後）。日時・会場・人数と、確認事項の質問が入ります。見積・申込確認のときは、Googleフォームの案内が入ります
見積のご案内文見積書に添える文と、内訳のひな形。お見積り金額・内訳・交通費・有効期限は〔 〕で、人が入れます（システムは金額を作りません）。フォームの案内つき
申込書託児申込書のひな形。案件とお客さまの情報が入り、アレルギー・キャンセルの決まりは〔 〕で、お客さまに確かめて入れます。お名前・日付の記入欄つき

  1. 1下書きの種類を選ぶボタンを押すと、数秒で下書きが出ます。返信文・スタッフへの依頼文は、上の「LINE向けの短い文にする」に印をつけてから押すと、あいさつを短く、行を分けた文になります（公式LINEに貼り付けるとき用）。
  2. 23読んで、直す枠の中は、そのまま書きかえられます。AIの下書きなので、宛名・日時・人数を必ず確かめてください。
  3. 4〔 〕を書きかえる情報が足りない所は、〔 〕で残っています（例:〔集合の時刻と場所〕）。書きかえると、残りの数が減ります。
  4. 5「内容を確かめました」に印をつける印をつけるまで、コピーのボタンは押せません。
  5. 6「コピーする」を押して、貼り付けて送るメールやLINEなどに貼り付けて、担当者が自分で送ります。システムは送信しません。

内容を変えたいとき（案件の情報を直したあとなど）は、「作り直す」を押します。

3.7　タスクを管理する

「タスク」の画面には、すべての案件のタスクが、期限の近い順に並びます（未完了が上）。期限を過ぎたものは、赤い文字と印で出ます。

  1. 12絞り込むステータス（未完了のみ・すべて・未着手・進行中・完了）、担当者、期限（期限切れ・今日・今週）で絞り込めます。
  2. 3終わったら、左の丸を押す完了になります。もう一度押すと、未着手に戻ります。
  3. 4ステータスを変える「未着手」「進行中」「完了」を選びます。
  4. 5「タスクを登録」タスク名・期限・担当者・ステータス・関連する案件を入れます（案件の詳細の「タスクを追加」からも登録できます）。

定型タスクを使う・使わない

「定型タスクの設定」を押すと、ステータスを進めたときに作られるタスクを、1つずつ「使う・使わない」にできます（初めは、すべて使う）。事務所のやり方に合わないものは、外してください。

3.8　実施したあとに、実績を記録する

託児が終わったら、実際の人数・時間・申し送りを「実績」に残します。予定との差が分かり、申し送りは次の引き継ぎメモにも使われます。

  1. 登録する案件を選ぶ「実績」の画面の「実績の登録待ち」（開催日を過ぎたが、実績がまだない案件）から、「実績を登録」を押します。案件の詳細の「実績」の欄からも登録できます。
  2. 12案件・実施日・時間実施日には、未来の日は選べません。予定の時間が最初から入っています。
  3. 3実際の人数実際の子どもの人数と、スタッフの人数を入れます。0人のときは 0 と入れてください（空のままでは登録できません）。
  4. 4申し送り事項次に同じお客さまの託児をする人へ、よかったこと・困ったこと・次に気をつけることを書きます。
  5. 5必要なら「案件を完了にする」に印印をつけると、案件が「完了」になります。つけないときは、「実施済み」になります。

登録すると、案件のステータスが進み、その案件の「実績を登録する」タスクも完了になります（「実施済み」に進んだときは、請求準備などの定型タスクも作られます）。実績を直すときは、案件の詳細の「実績を編集」を押します。

3.9　請求に必要な情報をまとめて、経理へ引き継ぐ

実施したあと、請求のために経理へ渡す情報を、案件ごとにまとめます。請求額は計算しません。実施日・時間・人数・スタッフ・交通費を、そのまま使える形にそろえます。「実績」の画面の「請求準備」の欄から使います。

  1. 「請求準備」の一覧から、「まとめを見る」を押す一覧には、案件ごとの交通費の合計・状態（未着手・準備できた・経理へ引き継ぎ済み）・足りないことの件数が並びます。
  2. 1足りないことを見る実績がない・交通費が未入力や未確定・実績の人数と確定した人数のちがい、などが出ます。先に、直してください。
  3. 23表と合計を見る確定したスタッフごとの行と、交通費の単純な合計が出ます。
  4. 4書き出す・コピーする「CSVで書き出す」は、Excelで開ける形（文字化けしない形）で保存します。「表をコピー」は、Googleスプレッドシートにそのまま貼り付けられます。一覧の上のボタンで、引き継ぎ前の案件をまとめて出すこともできます。
  5. 5状態を「経理へ引き継ぎ済み」にする足りないことが残っているときは、「承知のうえで」の印が必要です。引き継ぐと、「経理へ引き継ぐ」のタスクも完了になります。
CSVの中の文字について

お客さまの名前などが「=」「+」「-」「@」で始まっていると、表計算ソフトが式として動かしてしまうことがあります。書き出すときは、そうした文字の先頭に「'」をつけて、式として動かない形にしています。

04Daily use

毎日の使いかた

1日のはじめと、場面ごとの確認のしかたの例です。事務所の運用に合わせて、調整してください。

毎朝

  • ダッシュボードを開く
  • 「期限切れのタスク」を先に片づける（担当・期限を確かめる）
  • 「今日対応するタスク」を見て、1日の予定を決める
  • 「これからの案件」で、赤い「不足」の案件がないか見る

  • AIアシスタントで整理する
  • 原文と見比べて、まちがい・抜けを直す
  • 案件に登録する（ヒアリングのタスクが作られる）
  • 返信文の下書きを作り、確かめて送る（LINEなら、短い文にする）

見積・申込のとき

  • 見積のご案内文を作り、金額を入れて、見積書と一緒に送る
  • ステータスを「見積」に進める（定型タスクが作られる）
  • 届いたGoogleフォームの回答を、案件と突き合わせて確かめる
  • 「申込確認」に進め、必要スタッフ数を決めて、案件に入れる

スタッフを手配するとき

  • 「スタッフ候補を探す」で候補を見る
  • 依頼文の下書きを作り、確かめて送る
  • 「依頼中で追加」で記録する
  • 返事をもらったら「確定」にする
  • 確定の数が必要数に届いたことを確かめる
  • 交通費を入れて、確定にする

毎週（常設託児室）

  • シフト表で、来週の枠を作る（この週の枠を作る）
  • 赤い「未手配」の枠に、スタッフを手配する
  • 依頼中のスタッフの返事を確かめて、確定にする

開催の前日から当日

  • ステータスを「最終確認」に進める
  • 持ち物・名簿・集合時間を確かめ、タスクを完了にする
  • 担当を交代するときは、引き継ぎメモを作って渡す

実施したあと

  • 「実施済み」に進める
  • 実績（人数・時間・申し送り）を登録する
  • 請求準備で、足りないことがないか確かめる
  • CSVを書き出し（または表をコピーし）、経理へ引き継ぐ
  • お客さまへの報告のタスクを済ませる
  • 終わっていないタスクがなければ「完了」に進める

06Troubleshooting

困ったとき

こんなときこうします
画面を再読み込みしたら、データが消えた？再読み込みでは消えません。タブを閉じると、最初のサンプルに戻ります（デモの決まりです）。
「スタッフ候補を探す」で、探せないと出る開催日と、開始・終了の時刻が入っていません。「案件を編集」で入れてください。
スタッフ候補が0名「条件に合わない」の理由を見てください。時間の相談をするか、スタッフの曜日・時間の登録が古くないか、確かめます。
ステータスを進めようとしたら、知らせが出た内容を確かめ、先に済ませるか、問題なければ「このまま進める」を押します。止められることはありません。
AIの整理結果が、まちがっている・「見つかりません」が多い入力欄で直します。AIは決まった書き方から取り出す仮の処理なので、書き方によっては読み取れません。原文と見比べて確かめてください。
「案件に登録」・「コピーする」のボタンが押せない「確かめました」の印がついていません。内容を確かめて、印をつけてください。
コピーができなかった下書きの文が選ばれた状態になります。キーボードでコピー（Macは ⌘＋C、Windowsは Ctrl＋C）してください。
実績を登録したい案件が出てこない実績を登録できるのは、開催日を過ぎて「最終確認」以降になった案件か、「実施済み」の案件です。ステータスを確かめてください。
実施日に「未来の日は選べません」と出た実施日は、今日以前の日にします。実施したあとに登録してください。
入力欄に、赤い文字が出た赤い文字が、何がだめで、どう直すかを書いています。そのとおりに直してください。
案件・タスク・スタッフを削除したい削除の操作はありません。スタッフの休止は「休止中」にします。担当スタッフを外す操作だけ、案件の詳細でできます。
Googleフォームに回答があったのに、「未確認の回答」に出ない管理者に伝えてください。フォームの送信の設定（スクリプト）と、フォームに「開催日」「会社名（お名前）」にあたる質問があるかを確かめます。急ぐときは、回答のスプレッドシートを見て、案件に手で入れられます。
回答が「一致する案件がありません」と出る開催日や顧客名が、案件と大きくちがっています。取り込む案件を選び直すか、「新しい案件として登録する」を選びます。
「相違」の項目は、どちらが正しい？システムには決められません。お客さまに確かめてから、反映するかを選びます。反映しなければ、案件の登録はそのままです。
返信文に〔GoogleフォームのURL〕と出る「案件」の「Googleフォームの設定」で、フォームの URL を入れてください（https で始まる URL だけ）。
シフト表の週に、枠がない「この週の枠を作る」を押します。定期シフトが決まっていない場所は、先に「定期シフトの設定」で決めます。
枠に入れたい人が、選べない手配の画面の「入れない人」で、理由を見ます。曜日・時間が合わない、休止中、同じ時間にほかの案件や枠に入っている、のどれかです。
交通費を「確定」にできない金額が未入力です。金額を入れてください（かからないときは 0）。
請求のまとめで、「引き継ぎ済み」にできない足りないことが残っています。先に直すか、確かめたうえで「承知のうえで」に印をつけます。
CSVを開くと、文字化けするExcelで開ける形（UTF-8・BOMつき）で書き出しています。それでも化けるときは、「表をコピー」で、スプレッドシートに貼り付けてください。
定型タスクが、ほしくない「タスク」の「定型タスクの設定」で、使わないものの印を外します。すでに作られたタスクは、そのまま残ります。
最初の状態にやり直したいメニューの下の「サンプルデータに戻す」を押します。登録したものは、すべて消えます。
